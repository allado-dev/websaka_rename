# Webサカ Model Helper

Webサカのゲーム画面に表示されるモデル選手名を、対応する実在選手名へ置き換えるChrome拡張機能です。

この拡張機能は非公式ツールです。Webサカおよび運営会社とは関係ありません。

## 主な機能

- チーム編成などの通常画面では、一般的な登録名や日本人選手の姓名を表示
- 選手詳細では、実在選手のフルネームと元のゲーム内名を併記
- 成績表ではチーム名を残したまま選手名だけを置換
- 強化ショップの候補選手名にも対応
- 明るい背景用と暗い背景用の選手名カラーを設定可能
- 設定した2色から、背景に対して読みやすい色を自動選択
- 拡張機能のポップアップから表示のON/OFFが可能

## インストール

この拡張機能はChromeウェブストアでは配布していません。

1. GitHubの「Code」から「Download ZIP」を選びます。
2. ダウンロードしたZIPを展開します。
3. Chromeで `chrome://extensions/` を開きます。
4. 右上の「デベロッパーモード」をONにします。
5. 「パッケージ化されていない拡張機能を読み込む」を選びます。
6. 展開したフォルダのうち、`manifest.json` があるフォルダを指定します。
7. Webサカのページを再読み込みします。

旧版を利用している場合は、二重に置換されないよう旧版をOFFにしてください。

## 使い方

インストール後は対象画面の選手名が自動的に置き換わります。
Chromeのツールバーから拡張機能を開くと、表示のON/OFFと選手名の色を設定できます。
反映されない場合はWebサカのページを再読み込みしてください。

## プライバシーと安全性

- 表示の置換はブラウザ内だけで行い、ゲームサーバーのデータを変更しません。
- ゲームの自動操作、クリック自動化、API改変は行いません。
- Cookie、セッショントークン、フォーム入力値を取得または保存しません。
- 設定の保存にはChrome拡張機能のローカルストレージを使用します。

## 更新方法

最新版をダウンロードして既存フォルダを置き換えた後、`chrome://extensions/` で拡張機能の再読み込みボタンを押してください。その後、Webサカのページも再読み込みします。

## 対応環境

- Google Chrome
- Chrome Manifest V3
- Yahoo!モバゲー版を含むWebサカの対応ドメイン
